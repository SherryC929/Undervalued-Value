# Release

## Function

A website where users walk through an imagined life, picking up things they desire and gradually releasing them until only one can be carried to the end.

## Value

**Release**

## Concept

We often move through life collecting things we want: love, money, health, freedom, memories, dreams, and the people we care about. But the more we carry, the heavier the journey becomes.

This website turns life into a journey of carrying and letting go. Users can pick up different desires along the way, but as they move forward, they must gradually release some of them. Eventually, only one can be carried to the end.

There is no objectively right thing to keep. Users can also choose to stop their journey when they feel they can no longer release anything.

The project explores what we hold onto, what we are willing to release, and what makes a journey worth continuing.
